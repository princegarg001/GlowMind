# Audio Assets for GlowMind Mood Swiper

This directory contains audio files for the immersive mood swiper feature.

## Default Placeholder URLs

Since we cannot bundle large audio files in the repository, we use placeholder URLs 
that point to royalty-free audio sources. Users can replace these with their own 
audio files or the app will download them on first use.
